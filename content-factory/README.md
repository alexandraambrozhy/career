# Контент-экосистема «100 дней до 25»

```
Голос в приложении Claude → проект «Сценарист» (claude.ai) → Notion (склад) → Карта смыслов (витрина)
```

- **Склад — Notion.** «Темы и контент», «Входящие мысли», «Конкуренты» и «🧰 Приёмы и примеры»
  (формулы хуков, структуры, CTA, удачные приёмы конкурентов). На странице темы одна чистая версия
  сценария; прошлые версии лежат в свёрнутом блоке «Архив версий». Образец: «ИИ-слоп и безопасность ИИ в бизнесе».
- **Генератор — проект «Сценарист».** Инструкция и текст для Instructions лежат в Notion:
  «Сценарист: проект для сценариев». Сценарист пишет сценарий прямо на страницу темы в Notion.
- **Витрина — `karta.html`**, опубликована как https://claude.ai/artifact/HtrqjjMR3sUrrm5zTvCJRS.
  Читает обе базы из Notion при открытии, держит последний снимок в artifact db (`snapshot/notion`).

`index.html` — первая версия («Контент-завод»), её заменила схема выше.
