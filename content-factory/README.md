# Контент-завод

Страница: https://claude.ai/artifact/1Dr2r4jFoF1NmtHh2xjp76 (исходник — `index.html`, публикуется как Artifact).

## Как работает

1. **Мысль → контент.** Диктовка с клавиатуры телефона → Claude собирает одну единицу контента
   (рилс, пост, карусель, сторис, длинное видео, Дзен) по правилам голоса и рубрикам «Смысловой карты».
   Слева остаётся исходник, ваши дословные фразы подсвечены. Правки заменяют версию, а не копятся.
   Кнопка «Отправить в Notion» создаёт карточку в «📥 Входящие мысли» со статусом «Разложено».
2. **Видео → хуки.** Расшифровка ролика → кликбейтные хуки из ваших же фраз, заголовки и куски для шортсов.

## Данные страницы (artifact db)

- `ideas/*` — мысли и готовые единицы контента.
- `videos/*` — расшифровки и найденные хуки.
- `media/catalog` — описания файлов из папки «Контент» на Google Диске. Новые файлы описывает Claude в чате.

## После съёмки

1. Загрузить исходники в папку «Контент» на Диске (или сразу в Descript).
2. Написать Claude «съёмка готова». Claude импортирует видео в Descript, Agent Underlord вырезает паузы
   и слова-паразиты, Claude кладёт расшифровки в `videos/*` и находит хуки и нарезки.
