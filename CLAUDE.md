# Контент Александры Амброжий

Помимо сайта (`index.html`), этот репозиторий — рабочее место для контента. Александра присылает голосовое или мысль, Claude превращает её в сценарий, а по запросу — в карусель.

## О чём она пишет
- Психология, коучинг, карьерное консультирование.
- Не делать акцент на резюме, собеседованиях и поиске работы: это не её голос.
- Не использовать фазы кампании («Листопад», «Корни» и т. д.) и рубрики.
- Голос и запреты описаны в навыке «golos-aleksandry». Главное: основа — её слова, свои связки выделять курсивом, факты только реальные и с источником.

## Мысль → сценарий
1. Сохранить мысль во «Входящие мысли»: Мысль, Суть (её слова дословно), Статус «Новая».
2. Подобрать 2–4 приёма из «Приёмов и примеров».
3. Написать на странице мысли ОДНУ версию по образцу: плашка (формат · длительность · статус), хук + 2 запасных, таблица «Сек | Говорю | Титр | Кадр», подпись, «Зачем это зрителю», приёмы (ссылками), «Уточнить» чек-листом, источники.
4. Если сценарий уже был — старое убрать в свёрнутый блок «Архив версий» внизу, не складывать версии друг на друга.
5. В ответе — одна строка и ссылка. Без пересказа.

## Сценарий → карусель
Шаблон: `content-factory/carousel/template.html` — её стиль (квадрат, рендер 2160×2160): кремовый фон, «Александра Амброжий» сверху, рукописная надпись Marck Script красным, жирный заголовок Onest 800 с красным акцентом, белые карточки с цветными номерами, тёмная плашка, бордовые звёзды, «глобус» из линий, жёлтые и розовые круги. Готовые макеты слайдов в шаблоне: обложка на фото, буллеты, 2×2 карточки, фото на половину слайда + список, таймлайн с графиком, плашки-цитаты + вопросы, финал на фото с двумя кнопками.
1. Скопировать шаблон, заменить тексты, выбрать подходящие макеты. Первый и последний слайд — атмосферное фото, в середине хотя бы один слайд с её портретом.
2. Фото взять с Диска (`download_file_content`), HEIC перевести в JPG (`pillow-heif`), положить рядом с html. Фото в репозиторий не коммитить.
3. Отрисовать: `NODE_PATH=$(npm root -g) node content-factory/carousel/render.js <файл.html> <папка>`.
4. Посмотреть результат глазами, поправить наложения, отправить PNG Александре файлами.
