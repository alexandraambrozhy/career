# AI-рекрутер (MVP, аналог Qooqa)

Ускоряет первичный подбор: Telegram-бот сам общается с кандидатами, собирает ответы и резюме,
Claude оценивает соответствие вакансии, а рекрутер получает готовый шорт-лист.

## Как это работает

1. Рекрутер создаёт вакансию в веб-панели: описание, требования, скрининговые вопросы, порог.
2. Панель выдаёт ссылку `https://t.me/<бот>?start=vac_<id>`, её размещают в объявлениях.
3. Бот получает согласие на обработку ПД, спрашивает имя и контакт, задаёт вопросы и
   принимает резюме (PDF / DOCX / TXT или текстом).
4. Claude выставляет оценку 0–100, вердикт, сводку, сильные стороны, риски и вопросы для интервью.
5. Если оценка выше порога, рекрутеры сразу получают уведомление в Telegram.
6. В панели: рейтинг кандидатов по вакансии, карточка кандидата, статусы
   (Новый → Шорт-лист → Интервью → Оффер / Отказ) и экспорт в CSV.

Без `ANTHROPIC_API_KEY` работает **демо-режим**: оценка по совпадению ключевых слов из требований.

## Режим «от вашего имени» (Telegram Business)

Кандидаты пишут в ваш **личный** Telegram, а бот отвечает в этом же чате от вашего имени:
здоровается, уточняет вакансию, спрашивает согласие, задаёт вопросы, просит резюме и оценивает.
Вы получаете уведомление о подходящих кандидатах от бота.

- Стоит написать в чат самим, и бот в нём замолкает: дальше разговор ведёте вы.
- После анкеты бот тоже молчит, на следующие сообщения кандидата отвечаете вы.
- Тем, кто уже проходил анкету, бот не пишет повторно.
- Если вакансий несколько, бот ищет название вакансии в первом сообщении, а если не находит,
  присылает список с номерами.

Как подключить:

1. Нужна подписка **Telegram Premium** на вашем аккаунте: Telegram Business входит в неё.
2. В [@BotFather](https://t.me/BotFather): ваш бот → *Bot Settings* → *Business Mode* → включить.
3. Нажмите /start у своего бота, чтобы он мог присылать вам уведомления.
4. В Telegram: *Настройки → Telegram для бизнеса → Чат-боты*, введите имя бота и разрешите
   ему отвечать на сообщения.
5. В доступе к чатам **исключите контакты** (друзей, коллег), чтобы бот отвечал только новым людям.
6. Укажите в вакансиях свой ник: «Откликнуться: напишите @ваш_ник».

## Запуск

```bash
cd ai-recruiter
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполните токен бота, пароль панели, chat ID рекрутеров
set -a && source .env && set +a
python main.py
```

Панель: http://localhost:8000 (логин и пароль из `ADMIN_USER` / `ADMIN_PASSWORD`).

Через Docker:

```bash
docker build -t ai-recruiter .
docker run --env-file .env -p 8000:8000 -v recruiter-data:/data ai-recruiter
```

### Что понадобится

- **Токен бота**: создайте бота у [@BotFather](https://t.me/BotFather).
- **Chat ID рекрутеров**: напишите [@userinfobot](https://t.me/userinfobot), затем нажмите /start у своего бота,
  чтобы он мог вам писать.
- **Ключ Anthropic API**: на [console.anthropic.com](https://console.anthropic.com). Модель по умолчанию —
  `claude-opus-5-5`, меняется через `CLAUDE_MODEL`.

## Структура

| Файл | Назначение |
|---|---|
| `main.py` | запускает панель и бота в одном процессе |
| `app/bot.py` | сценарий диалога с кандидатом в боте (aiogram 3) |
| `app/business.py` | тот же скрининг в вашем личном чате через Telegram Business |
| `app/scoring.py` | оценка кандидата через Claude и демо-режим |
| `app/resume.py` | извлечение текста из PDF/DOCX/TXT |
| `app/web.py`, `app/templates/` | веб-панель рекрутера (FastAPI) |
| `app/db.py` | хранилище SQLite |

## Важно

- **152-ФЗ.** Бот запрашивает согласие на обработку ПД. Перед запуском разместите политику
  обработки персональных данных и укажите на неё ссылку в описании бота. Данные кандидатов
  передаются в Anthropic API для оценки — это тоже стоит отразить в политике.
- **Без дискриминации.** В промпте модели запрещено учитывать пол, возраст, национальность и другие
  нерабочие признаки. Оценку ИИ используйте как подсказку: решение об отказе принимает человек.
- Состояние диалога хранится в памяти: если перезапустить бот, кандидатам с незаконченной анкетой
  придётся начать заново.
